# AndroidLearning

A learning project to figure out how native Android applications are developed using **Kotlin** and **Jetpack Compose**.

## About this project

This is a simple project to develop my knowledge and practical experience of native Android development.

I am planning to build an app and wanted to explore Android/Apple and PWA development to better understand my options.

The project will be built in 3 stages, starting with a simple Hello World type app, progressing to add various common app elements, and finally a simple cohesive ToDo type app with multiple screens, user interaction and data persistence.

I will be repeating the same process for Native Apple and a Progressive Web App to explore the differences in the process and make a more informed decision on how to proceed for my production App, MechaBob.

The emphasis is on understanding the underlying technologies and development principles rather than simply following tutorials or copying code.

## Technologies

- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **IDE:** Android Studio
- **Version Control:** Git and GitHub
- **Minimum Android Version:** Android 7.0 (API 24)

## Learning Roadmap

### Stage 1 – Basic Android Application

- Create a simple Android application.
- Understand the structure of an Android Studio project.
- Explore Activities and the Android application lifecycle.
- Learn the fundamentals of Kotlin and Jetpack Compose.
- Create user interfaces using Composable functions.
- Understand and use Android Studio Previews.

### Stage 2 – Multiple Screens and Interaction

- Create an application with multiple screens.
- Explore navigation between screens.
- Introduce menus and user interaction.
- Work with state and dynamically updated interfaces.
- Build simple interactive features such as counters.

### Stage 3 – To Do Application

- Design and build a simple To Do application.
- Display and manage a list of tasks.
- Implement Create, Read, Update and Delete (CRUD) functionality.
- Introduce local data persistence.
- Explore application structure and separation of responsibilities.

## Development Approach

The project is being developed incrementally, with each stage building on knowledge gained from the previous one.

Git is used to record development progress and maintain a history of changes.
